# 학습노트 운영 규칙

docs/learning-notes.md는 프로젝트의 기능 목록이 아니라 개발 교재로 사용한다. 각 완료 Task마다 다음 형식으로 기록한다.

## 기록 템플릿

### 무엇을 바꿨나

사용자 관점의 변화와 수정한 파일을 한두 문장으로 쓴다.

### 왜 이렇게 설계했나

대안과 트레이드오프를 포함해 결정 이유를 설명한다.

### 핵심 개념과 흐름

입력 → 상태/엔진 → 화면 또는 서버 저장의 흐름을 초보자도 따라갈 수 있게 쓴다.

### 검증과 디버깅

실행한 명령, 통과 여부, 실패 원인과 해결 방법을 남긴다. 실행하지 않은 검사는 통과로 표시하지 않는다.

### 다음 연습

같은 개념을 사용자가 직접 확장해 볼 작은 과제를 하나 제안한다.

사용자 결정, 코드에서 확인한 사실, 범위를 벗어난 발견을 서로 다른 문단으로 구분한다.
