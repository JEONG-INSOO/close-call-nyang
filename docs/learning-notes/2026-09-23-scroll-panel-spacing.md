# 스크롤 패널 위·아래 여백 정리

## 무엇을 바꿨나

메인, 결과, 설정(캐릭터·랭킹 포함), 가상 광고, 공유 피드백처럼 `ScrollView`를 사용하는 패널의 콘텐츠에 위·아래 28px 여백을 적용했다. 가로 여백과 버튼 사이 간격은 기존 값을 유지했다.

핵심 패턴은 `padding`을 한 번에 덮어쓰는 대신 축별 속성을 명시하는 것이다.

```tsx
content: {
  paddingHorizontal: 20,
  paddingTop: 28,
  paddingBottom: 28,
}
```

## 왜 필요한가

세로 공간이 부족해 스크롤되는 화면에서도 첫 버튼과 마지막 버튼이 카드 경계에 붙어 보이지 않게 한다. 공통 프레임인 `SettingsPanel`을 수정했기 때문에 캐릭터 선택과 리더보드에도 같은 규칙이 적용된다.

## 확인할 것

- 짧은 화면과 가로 모드에서 마지막 버튼이 잘리지 않고 스크롤되는지 확인한다.
- 여백은 시각적 변경이므로 실제 Expo Go 기기에서 손가락 스크롤과 함께 확인한다.

## 다음 연습

`paddingVertical`과 `paddingHorizontal`을 분리해 쓰면 어떤 방향의 여백만 바꿀지 명확해진다. 다음에는 공통 디자인 토큰으로 패널 여백을 추출해 화면별 중복을 줄여본다.
