# 2026-09-23 · 부활 광고 위치와 덱스컨설팅 문구

## 무엇을 바꿨나

결과 화면의 광고 부활 버튼을 점수와 최고 기록 바로 아래로 올리고, 이름을 `광고 보고 일어서기`로 바꿨다. 개발용 가상 광고의 브랜드·본문·보상 문구를 `DEXCONSULTING · 덱스컨설팅` 콘셉트로 교체했다.

## 왜 이렇게 설계했나

부활은 결과 화면에서 가장 중요한 다음 행동이므로 상단에 배치해 발견성을 높였다. 실제 광고 SDK는 아직 연결하지 않았기 때문에 문구 변경은 가상 광고 화면에만 적용된다.

## 검증

TypeScript typecheck와 광고·결과 화면·엔진 관련 Jest 58개 테스트를 통과했다.

실제 광고 SDK를 연결할 때 광고 완료 콜백과 보상 중복 방지 조건을 설계해 본다.
