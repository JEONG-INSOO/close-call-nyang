# 2026-09-22 생성 이미지 부품으로 만든 우측 진행 신입 캐릭터

## 무엇을 바꿨나
- 기본 rookie를 손으로 쓴 SVG에서 **이미지 생성 도구로 만든 부위별 PNG**로 교체했다. 머리 1장 + 표정 3장(평소/위험/넘어짐) + 몸통·다리 2·꼬리·팔 4종.
- 몸은 오른쪽을 향한 3/4 각도, 꼬리는 뒤(왼쪽), 발끝은 오른쪽. 다리는 엉덩이 축으로 ±22° 교대하고 팔은 반대로 흔든다.
- 표정: |기울기| < 40° 평소, ≥ 40° 위험(땀방울 + 두 팔 번쩍), 넘어지면 `> <` 찡그림. 넘어질 때 머리를 -45°로 되돌려 표정이 옆으로 눕지 않게 했다. 표시 전용이며 65° 실패 판정은 그대로다.
- 커피(15%부터)는 오른팔을 커피 든 팔로 바꾸고, 위험 상태에서도 컵은 손에 남는다.
- 보상 diligent/veteran은 기존 크림색 SVG 그대로다(다음 단계 P02에서 같은 방식으로 교체 예정).

## 부품 파이프라인
- 원본: `docs/art/source/` (몸 시트 webp, 표정 시트 webp, 팔 시트 png, 스타일 레퍼런스).
- `node scripts/build-rookie-parts.mjs` → `assets/characters/rookie/*.png`
  1. `scripts/split-art-sheet.mjs`가 초록 배경(#00FF00)을 크로마키로 지우고 덩어리별 PNG로 자른다(가장자리 초록 번짐 제거, 작은 로고 조각은 최소 면적으로 제외).
  2. 머리에 원래 그려진 `ω` 입을 흰 주둥이 색으로 지운다(코는 보존).
  3. 눈·눈썹·입·땀방울을 머리 좌표에 맞춰 2배 해상도로 합성해 표정 3장을 만든다.
  4. 부품은 정렬 순서 + 예상 크기로 고르며, 새 시트의 배치가 다르면 크기 검사에서 실패한다(엉뚱한 부품이 조용히 들어가지 않게).
- 조립 좌표는 `src/scene/RookieSprite.tsx`에 소스 픽셀 단위로 있고, 543px 높이를 기존 리그 높이 200으로 줄인다(`ROOKIE_ART.scale`).

## 사용자 피드백으로 조정한 것
- 첫 SVG 시안(v1~v5)은 스타일이 맞지 않아 폐기 → 레퍼런스 스타일의 이미지 생성 방식(B안)으로 전환.
- 다리 보이는 길이 절반(엉덩이 축을 다리 이미지 안쪽 85~90px 지점으로), 팔도 약 절반(80% 크기 + 재킷 뒤에 어깨를 숨김).
- 팔: 처음 시트의 팔꿈치 꺾인 팔은 "진짜 팔 같아서" 어색 → 두 번째 시트의 늘어뜨린 팔/든 팔/커피 팔로 교체. 늘어뜨린 팔은 재킷 **뒤**, 든 팔은 큰 머리에 가려지므로 머리 **앞**에 둔다.
- 오른팔을 좌우 반전하는 대신 좌우 어깨에 붙일 그림을 바꾸는 게 맞았다(사용자 지적).

## 겪은 문제
- 장면 테스트 번들(`export:embed`)은 이미지를 `/assets/...` 루트 절대경로로 등록해 `/fixtures/` 아래에서 404가 났다. `build-scene-fixtures.mjs`에서 상대경로(`./assets/assets/`)로 바꿔 해결. 실제 `dist`는 `/close-call-nyang/assets/...`로 정상.
- 포즈 시트 "어어어?!" 카드(0.8 rad)는 보호 윤곽·숨긴 팔까지 포함한 getBBox가 viewBox를 넘어 e2e 실패 → viewBox를 `-160 -250 380 330`으로 넓힘.
- 셸 heredoc 안의 긴 JSX 문자열이 bash 파싱에 실패 → 파일 쓰기 도구로 직접 작성.

## 후속 수정: 다리 간격과 팔 테두리
- 다리 엉덩이 축 x를 -22/26 → -12/16으로 옮겨 두 다리를 몸 가운데로 모았다(사용자 선택: "두 다리를 더 붙이기").
- 팔 테두리: 부위별 외곽선 두께를 픽셀로 재 보니 화면 기준 머리 9·몸통 8·다리 7·꼬리 8인데 팔은 3~4였다(팔 시트가 더 작게 그려짐). `build-rookie-parts.mjs`가 팔 PNG마다 6px 투명 여백을 두고 외곽선을 바깥으로 2~4px, 안쪽 선을 1px 키운다 → 팔도 약 8.
- 이 과정에서 발견: 팔을 화면 평면에서 앞뒤로 흔들면 걸음 위상의 절반 동안 앞발이 몸통 안쪽으로 돌아가 재킷 뒤에 숨었다. 기본 각도를 바깥 16°로 벌리고 흔들림을 ±6~8°로 줄여 항상 바깥에 보이게 했다(회귀 테스트 추가).
