# 학습노트: 15m 이후 점진적 난이도

## 무엇을 바꿨나

- 15m 전에는 기존의 부드러운 균형 drift를 유지한다.
- 15m 이후에는 거리 레벨을 이용해 drift 파형의 재생 속도를 점진적으로 높인다. 최대 속도 배율은 2.8로 제한했다.
- 불안정도와 외란 폭을 조금씩 키우고, 이벤트 강도도 증가시켰다.
- 이벤트 간격은 거리 레벨에 따라 줄어들지만 최소 4초 아래로 내려가지 않는다.
- 이벤트의 경고 1.2초와 활성 0.7초 구조, 65도 실패 각도는 그대로 보존했다.

## 왜 이렇게 했나

처음부터 빠르게 흔들리면 조작법을 익히기 전에 실패할 수 있다. 그래서 커피를 얻는 15m를 난이도 전환점으로 사용했다. 기울기 파형의 속도를 거리와 연결하면 단순히 진폭만 키우는 것보다 좌우 전환이 “휙휙” 느껴지면서도 초반 적응 구간은 유지된다.

## 랭킹 무결성

기울기 계산은 랭킹 판정에도 사용되므로 `scripts/sync-ranked-engine.mjs`로 Supabase 검증 사본을 함께 갱신했다. 새 규칙 버전은 `nyang-v1-bc732af6f2a7ea66`이며 101m 재생 골든도 새 물리에 맞춰 갱신했다.

## 검증

- TypeScript 타입 검사 통과
- 전체 Jest 654개 통과
- 랭킹 엔진 동기화 검사 통과
- 웹 export 및 온라인 fixture 재빌드 통과
- Chromium 전체 34개 통과, 11개는 기존 프로젝트 조건부 skip
- 처음 온라인 모바일 2건은 오래된 온라인 fixture 때문에 규칙 버전 불일치가 발생했으나 fixture 재빌드 후 2/2 통과

## 테스트 방법

서버가 실행 중이면 `http://localhost:4173/close-call-nyang/`에서 플레이한다. 15m 전후와 51m 이후를 비교하면 drift 속도와 이벤트 압박 증가를 확인할 수 있다.
