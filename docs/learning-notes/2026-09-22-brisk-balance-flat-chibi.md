## 무엇을 왜 바꿨나

### 1. 점수 속도와 화면 속도를 분리

`src/scene/layout.ts`의 `PIXELS_PER_METER`를40에서120으로 바꿨다. 원경/근경의 비율은 그대로여서 깊이감은 유지하고, 실제100%까지 걸리는 시간은 줄이지 않는다.

```ts
export const PIXELS_PER_METER = 120;
// 거리 × 시각 배율 × 레이어 비율 = 화면 이동량
```

카페와 회사 입구도 같은 배율을 쓰며15%커피,50.5%입구,51%사무실 정렬을 검사한다. 배경만 빠르게 만들고 랜드마크 좌표를 방치하면 커피를 받는 순간과 카페 위치가 어긋난다.

### 2. 첫3초 적응 뒤 능동적으로 균형 잡기

`src/game/difficulty.ts`의 `adaptationAt`는 활성 플레이 시간만으로0에서1까지 변한다.3초까지0,3~5초 부드럽게 증가,5초부터1이다. 카운트다운/정지 시간이 포함되지 않으며 무적 시간이 아니다. 한 방향을 계속 누르면 첫3초 안에도 넘어질 수 있다.

```ts
const pressure = adaptationAt(time);
const instability = 2.2 + pressure * (difficulty.instability - 2.2);
const amplitude = 0.18 + pressure * (difficulty.disturbance - 0.18);
const disturbance = amplitude * balanceDrift(time, run.seed);
```

최종 튜닝: 불안정도7.6+거리레벨×.9, 흔들림1.8+레벨×.22, 감쇠1.8. 기존 주기적인 사인파 대신 시드 기반의 매끄러운 불규칙 흔들림을 사용한다. 정수 해시와 smoothstep(양 끝이 부드러운 보간)으로 같은 시드/입력을 정확히 재생하며 사건용 난수 상태는 소비하지 않는다.100%이후 난이도도 계속 증가한다.

15%커피 이후 사건 대기는6초에서2초, 예고1.2초/작용.7초는 유지했다. 사건 간격은 `max(4, 6/(1+.2*level))`, 강도는 `1.6+.5*level`이다.65도 즉시 실패, 조작 힘9.6, 고정1/120초 틱, 좌우 동시 입력 상쇄, 일시정지, 실제 점수 속도는 유지했다.

### 3. 그림 전체를 평면 SVG로 다시 작성

`src/scene/NyangCharacter.tsx`는 전체200/머리104/몸78/발18 리그다. 따뜻한 갈색4.5 외곽선, 크림 몸·흰 입/배·분홍 젤리, 짧은 팔다리로 다시 그렸다. 정장/조끼/소매/바지/신발/이마 광택/음영을 제거하고 넥타이+사원증만 남겼다. 세 표정은 다르지만 ID와0/1/10회 해금 조건은 그대로다.

```ts
metersPerCycle: 2 * BALANCE.baseSpeedMps * BALANCE.footstepBaseSeconds
```

걸음 위상은 이동 거리에서 계산한다. 초기 양발 한 주기는.6초, 한 걸음은.3초이고 짧게±11도/들기5만 움직인다. 들어 올린 발에는 중앙 젤리와 발가락3개가 더 잘 보인다. 기울기는 실제 물리 각도를 그대로 사용하고 실패한 뒤만82도 넘어짐 애니메이션이 붙는다. `SharedValue`는 렌더러가 읽는 값이며 그림 코드가 게임 상태를 바꾸지 않는다.
