# 심사 안내 초안 — 미제출

현재 이름: 우당탕탕 냥대리. 문구는 사용자 미승인 초안이며 실제 TestFlight 확인 후 고친다.

- iPhone 가로 게임. 좌우 버튼으로 균형을 유지한다. 동시 누름은 중립 입력이며 자동 균형 보정이 아니다.
- 기본 게임에는 회원가입/로그인 화면이 없다. 새 설치에서 바로 플레이할 수 있다.
- 홈의 랭킹에서 닉네임을 설정하면 Supabase 기기별 익명 인증으로 온라인 참여한다. 심사용 비밀번호나 다른 플레이어의 토큰은 제공하지 않는다.
- 온라인에서 발급받은 도전의 입력을 서버가 재현·검증한 뒤 최고 기록을 등록한다. 결과의 `랭킹등록완료!`는 서버 응답 이후에 표시한다. Top 30 및 내 순위, 동점 공동 순위를 제공한다.
- 랭킹의 닉네임 변경, 다른 행의 신고/이 기기에서 숨김, 내 온라인 데이터 삭제를 확인할 수 있다. 삭제 위치·실제 화면 문구는 TestFlight QA에서 다시 확인한다.
- 숨김은 로컬 필터다. 신고는 서버에 접수되며 즉시 상대 계정을 삭제하지 않는다.
- 오프라인 플레이 가능. 오프라인으로 시작한 판은 순위 제외. 일시정지→홈→이어가기는 기기에 저장하며 DB 저장/다른 기기 복구가 아니다.
- 최고 기록·설정·캐릭터 수집은 로컬 데이터. 서로 다른 100% 달성 판 1회/10회로 두 캐릭터 해금, 능력치 차이 없음.
- 출시 프로필에서 가상 광고와 재현 진단은 꺼져 있다. 실제 광고 SDK/광고 추적은 포함하지 않는다. 광고 부활을 심사자에게 요구하지 않는다.
- 마이크 녹음과 백그라운드 녹음 기능 없음. 효과음/음악·햅틱 설정 제공.

## 제출 전 미완료 사항

지원/개인정보 URL은 metadata.json의 **예정 주소이며 현재 게시 완료가 아니다**. 운영자·지원 연락처·가격·지역·Apple 팀/앱 ID는 release-inputs.json의 null을 실제 확인값으로 채운다. 개인정보 라벨·연령 등급 설문·암호화 수출 응답도 아직 제출하지 않았다. 4+는 과거 목표이지 Apple의 확정 등급이 아니다. Made for Kids로 지정하지 않는다.

공개 심사 전 사용자가 소개 문구·아이콘·실제 스크린샷을 승인해야 한다. 내부 TestFlight 업로드와 App Review 제출은 별도 단계다.
