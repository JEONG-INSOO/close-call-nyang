# Decisions: 승인된 회색 태비 신입사원

- Date: 2026-09-22
- Status: Confirmed design; conservative implementation scope stated to user

## D01. 승인된 시안
- **Chosen**: 사용자는 영문 프롬프트로 생성한 네 포즈 이미지에 '좋아 이대로 개발해서 해줘'라고 승인했다. 회색 태비, 크고 밝은 눈, 웃는 얼굴, 재킷/칼라셔츠/작은넥타이/목걸이형 ID:001 사원증, 짧은 팔다리와 맨발 젤리다.
- **Rationale**: 최신 승인 시안이 이전 '넥타이+사원증만' 기본 신입 외형을 대체한다. 실패한 후속 평면색 보정이 아니라 실제 생성되어 보인 첫 이미지가 기준이다.

## D02. 기존 세 종과의 경계
- **Chosen**: 새 신입 시안을 기본 rookie에 우선 적용한다. 세종전체/기본만 질문에는 숫자답변이 없었으므로 전체보상까지 승인했다고 가정하지 않는다. 이 제한된 범위를 구현 전 사용자에게 명시했다. diligent/veteran 외형과0/1/10해금·저장·ID를 보존한다.
- **Rationale**: 프롬프트의 new office employee와 기본 신입이 대응하며 공유 몸체를 무조건 수정하면 보상도 바뀐다.

## D03. 게임과 시트 포즈
- **Chosen**: 실제 플레이는 새 SVG 외형+기존 거리 기반 걷기/65도기울기/커피. 걷기·물병·달리기·메모 네포즈를 동일부품으로 별도 시트에 제공한다. 물병을15%커피로 대체하거나 달리기를점수속도변경으로 해석하지 않는다.
- **Rationale**: SceneFrame은hasCoffee만가지며 그림은 상태를 읽기만 한다. 기존 물리/서버 규칙f7245064c9459310을 변경할 필요가 없다.

## D04. 제공 방식
- **Chosen**: 기존 react-native-svg 렌더러 유지, 승인 이미지의 주요 형태를 게임용 벡터 부품으로 재구성한다. 승인 원본을 docs/art에 보존하며 래스터와SVG가픽셀단위동일하다고 주장하지 않는다. 실제소스시트/게임화면PNG를검토하고 학습노트·로컬빌드·범위한정커밋까지 진행한다.
- **Rationale**: 기존 팔다리/기울기/정지 구독 유지와 해상도 독립 렌더링. 원격배포/푸시/이전dirty작업은 범위밖.
