# 스크롤 패널 여백 결정

## 결정

메인, 결과, 설정, 캐릭터 선택, 리더보드, 가상 광고, 공유 피드백 등 모든 스크롤 패널에 위·아래 여백을 적용한다.

## 선택 이유

사용자는 특정 화면이 아니라 버튼이 슬라이드되는 전체 UI에서 카드 경계와 첫·마지막 버튼 사이에 빈틈이 보이길 원했다. 설정 패널은 캐릭터와 리더보드가 공유하는 프레임이므로 공통 스타일을 한 곳에서 수정한다.

## 범위

- 세로 여백: 28px
- 기존 가로 여백과 버튼 간격: 유지
- 동작·콘텐츠·서버·광고 로직: 변경하지 않음
- 작은 화면: `ScrollView` 스크롤로 접근 가능해야 함

## 검증

TypeScript 타입 검사와 화면·설정·광고 프레젠테이션 테스트를 실행한다. 실제 Expo Go에서는 세로/가로 짧은 화면에서 첫·마지막 버튼이 카드 경계에 붙지 않는지 확인한다.
