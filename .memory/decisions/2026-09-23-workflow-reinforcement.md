# Decision: 2026-09-23 Workflow Reinforcement

## D01 목표
- 선택: 게임 완성과 개발 실력 향상을 동시에 완료 조건으로 삼는다.
- 근거: 사용자가 학습노트를 통해 다음 기능을 스스로 개발할 수 있기를 원함.

## D02 학습 기록
- 선택: 각 Task마다 변경 이유, 핵심 개념, 데이터 흐름, 검증, 디버깅 교훈, 다음 연습을 기록한다.
- 근거: 결과만 남기지 않고 재사용 가능한 지식으로 만들기 위함.

## D03 안전한 실행
- 선택: 기존 더티 변경 보존, Task 범위만 커밋, 커밋과 push 분리.
- 근거: 사용자 작업과 자동화 작업의 충돌 및 원격 변경을 방지하기 위함.

## D04 상태와 생성물
- 선택: pending/in_progress/blocked/done 상태를 사용하고, 규칙 변경 시 Supabase 복사본·웹 번들·replay fixture를 재생성한다.
- 근거: 현재 포인터 혼동과 오래된 생성물로 인한 테스트 오판을 방지하기 위함.
