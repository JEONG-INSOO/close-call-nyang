# Decisions: 첫 생성 이미지 분위기와 자연스러운 걸음

- Date: 2026-09-22
- Status: Confirmed

## D01. 최우선 기준
- **Chosen**: 사용자가 가장 좋다고 한 `docs/art/grey-tabby-approved-v1.png`의 **네 포즈 중 왼쪽 위 첫 번째 걷기 캐릭터**를 최우선 모델로 한다. 정면에 가까운 활기찬 걸음, 한쪽 발을 앞으로 들어 발바닥 젤리가 보이는 자세, 큰 둥근 얼굴, 통통하고 넓은 정장 몸통, 몸에 붙은 짧은 팔다리, 부드러운 회색 태비와 밝은 표정이다.
- **Rationale**: 직전 SVG는 요소 목록은 맞았지만 비율과 결합 방식이 달라 승인 이미지의 인상을 잃었다.

## D02. 보행과 발바닥
- **Chosen**: 첫 번째 걷기 포즈처럼 지면을 딛는 발은 발등만 보이고 젤리는 숨긴다. 발이 앞으로 들리는 짧은 구간에는 발바닥과 분홍 젤리가 분명하지만 과하지 않게 나타나며, 좌우 발이 교대로 그 포즈를 만든다. 발 전체를 계속 정면으로 보이지 않는다.
- **Rationale**: 현재 구현은 젤리를 항상 렌더링하고 크기만 줄여 자연스러운 발 구름이 없었다.

## D03. 팔다리 결합
- **Chosen**: 소매와 다리는 몸통 뒤에 겹쳐 어깨·엉덩이 접합선을 숨긴다. 손과 발은 더 짧고 둥글게 하며 중복 외곽선을 제거한다. 커피 손도 같은 겹침 원칙을 사용한다.
- **Rationale**: 독립 부품의 전체 윤곽선이 몸통 위에 노출되어 조립식처럼 보였다.

## D04. 보존 범위
- **Chosen**: 기본 rookie 외형/표현 애니메이션만 수정한다. 보상 캐릭터, 게임 물리, 15% 커피, 저장/해금/랭킹 규칙은 유지한다. 실제 작은 화면과 보행 위상별 캡처를 확인한다.
- **Rationale**: 피드백은 외형과 보행 연결 문제이며 게임 규칙 변경 요청이 아니다.
