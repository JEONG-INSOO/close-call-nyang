# Decisions: 15m Progressive Difficulty

- Date: 2026-09-23
- Status: Confirmed

## D01. 기울기 변화 난이도
- **Chosen**: 15m 이후부터 기울기 변화 속도와 흔들림 폭을 점진적으로 높인다.
- **Rationale**: 초반 적응 시간을 유지하면서 커피 획득 이후 긴장감을 높인다. 실패 각도 65도와 랭킹 물리 규칙은 유지한다.

## D02. 중간 이벤트 난이도
- **Chosen**: 15m 이후 이벤트 강도는 점진적으로 증가하고, 이벤트 간격은 기본 6초에서 최소 4초까지 짧아진다.
- **Rationale**: 기존 이벤트의 경고 1.2초와 활성 0.7초 구조를 보존하면서 후반 압박감만 강화한다.

## D03. 테스트 전달 방식
- **Chosen**: 로컬 웹 빌드와 자동 회귀 검사를 제공한다.
- **Rationale**: Mac 없이 즉시 확인할 수 있고, 현재 4173 서버 및 Playwright 픽스처 인프라를 재사용할 수 있다.
