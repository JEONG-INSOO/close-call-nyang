# Decisions: 베테랑 냥대리 — 다정한 멘토 아트 콘셉트

- Date: 2026-09-29
- Status: Visual proposal approved (게임용 프레임·구현은 아직 시작하지 않음)

## D01. 캐릭터의 인상
- **Chosen (사용자 선택)**: 주황빛 고양이인 다정한 멘토. 능청스러운 해결사나 냉철한 프로보다 따뜻하고 믿음직한 선배로 보인다.
- **Rationale**: 신입의 허둥댐, 성실한 냥대리의 밝은 렉돌 이미지와 감정·색상에서 차이를 만든다.

## D02. 털과 실루엣
- **Chosen (사용자 선택)**: 주황·흰색 단모. 흰 입가와 배, 이마와 꼬리에만 옅은 줄무늬. 복슬복슬한 장모로 만들지 않는다.
- **Rationale**: 성실한 렉돌의 풍성한 털과 겹치지 않고 게임 크기에서도 무늬가 복잡해지지 않는다.

## D03. 평소 얼굴과 눈 색
- **Chosen (사용자 선택)**: 부드러운 눈매, 잔잔한 미소, 올리브빛 초록 눈. 안경은 쓰지 않는다.
- **Rationale**: 기존 성실한 냥대리의 큰 파란 눈과 달라 보이고, 주황색 털과 대비되어 표정이 잘 읽힌다.

## D04. 복장과 소품
- **Chosen (사용자 선택)**: 짙은 숲색 니트 조끼, 아이보리 셔츠, 걷어 올린 소매, 조끼 주머니의 작은 펜. 손에 드는 소품은 없다.
- **Rationale**: 성실한 냥대리의 연보라 카디건과 옷 형태가 다르다. 앞발을 비워 게임 중 커피를 드는 상태와 충돌하지 않는다.
- **Existing convention (코드 확인)**: 직장인 캐릭터의 사원증과 커피 상태는 기존 게임 표현을 따른다. 펜은 작게 표현하되 화면 크기에서 보이지 않을 정도로 세밀하게 그리지는 않는다.

## D05. 걷는 인상
- **Chosen (사용자 선택)**: 차분하고 안정적인 걸음. 짧은 발이 번갈아 앞에 나오고 꼬리가 작게 흔들리며, 발을 들 때만 맨발 젤리가 살짝 보인다.
- **Rationale**: 다른 보상 캐릭터의 경쾌한 걸음과 구분하면서도 베테랑의 능숙함을 드러낸다.
- **Existing constraint (코드 확인)**: 걷기 그림은 시각 효과다. 거리, 실제 이동 속도, 기울기 물리, 점수, 랭킹 검증 규칙은 변경하지 않는다.

## D06. 위험과 넘어짐 표정
- **Chosen (사용자 선택)**: 위태로울 때는 침착하려 애쓰며 눈이 커지고 식은땀이 맺히지만 입을 꾹 다문다. 실제로 넘어지면 눈을 질끈 감고 작은 입을 벌린 멋쩍은 “아차!” 표정으로 바뀐다.
- **Rationale**: 평소의 잔잔한 미소와 구분되고, 넘어짐을 알아볼 수 있으면서도 다정한 성격을 유지한다.
- **Existing convention (코드 확인)**: 다른 캐릭터의 위험 표시는 기울기 절댓값 40°부터이고 `fallen`이면 넘어짐 표정이 우선한다. 베테랑 제작 시 이 표시 규칙을 재사용한다.

## D07. 기존 게임과의 접점
- **Existing convention (코드 확인)**: 저장 ID `veteran`, 서로 다른 100% 달성 10회 해금, 공통 짧은 팔다리와 화면상 체형, 사원증, 15% 이후 커피는 유지한다. 새 외형이 게임의 물리적 유불리를 만들지 않게 한다.
- **Rationale**: 외형을 교체해도 기존 해금 기록과 캐릭터 선택이 유지되어야 한다.

## D08. 승인된 기준 시안
- **Chosen (사용자 선택)**: [베테랑 냥대리 시안 v1](../../docs/art/proposals/veteran-mentor-concept-v1.png)을 외형의 기준 이미지로 승인했다.
- **Rationale**: 실제 걸음·위험·넘어짐 프레임을 만들 때 털색, 얼굴, 조끼, 주머니 펜, 사원증, 팔다리 길이를 이 시안과 일관되게 유지한다. 시안 한 장 자체가 걷기 애니메이션의 완성은 아니다.

## D09. 2026-09-29 후속 선택 — 채팅에 보낸 걷기 네 장
- **Chosen (사용자 선택)**: 이후 채팅 메시지에 보낸 주황색 베테랑의 네 장을 걷기 프레임으로 채택한다. 사용자가 지정한 `tabby-walk-frame-01..04.png`의 숫자 순서를 사용하며, 앞서 만든 `frame-1.png` 및 6칸 아틀라스와 **동일한 그림이 아니다**.
- **Implementation boundary**: 앞서 생성한 여섯 장/아틀라스에 대한 승인이 아니다. 네 장의 원본 PNG 파일이나 접근 가능한 절대 경로를 확보해 순서와 투명도를 확인한 뒤에만 T01 완료/커밋한다. 이전에 만든 위험·넘어짐 두 장은 유지할 후보로 남긴다.
- **Source obtained**: 사용자가 알려준 `C:/Users/mocca/Documents/Codex/2026-09-29/1-4-1-2-1-2/outputs/tabby-walk-frame-01..04.png`를 숫자 순서대로 복사·SHA-256 대조했다. 네 장은 1186×1326 투명 RGBA다. 이전에 생성한 설명의 첫 장 포즈와 새 선택 파일을 혼동하지 않는다.
- **Resolved visual tradeoff (사용자 확정)**: 01과 03 모두 화면 오른발 젤리가 보이며 왼발 전진 프레임은 없다. 이 한계를 알린 뒤 사용자가 **네 장을 수정 없이 그대로 사용**하겠다고 답했다. 따라서 D05의 이상적인 좌우 발 교대보다 이번에 고른 원본 보존을 우선한다. 동작이 어색하면 별도 후속 아트 작업으로 수정한다.

## 제작 전에 알아둘 점

- 사용자가 고른 **아트 콘셉트와 기준 시안**까지 확정되었다. 이 결정만으로 게임 코드 수정이나 배포가 완료된 것은 아니다.
- 성실한 냥대리는 네 걷기 장면과 위험·넘어짐 표정을 한 이미지 아틀라스에 묶어 렌더링한다. 베테랑도 제작 시 동일한 크기·발 기준점·표정 분기와 성능 검증을 고려하되, 구체적인 원본 장수와 이미지 제작 방식은 계획 단계에서 정한다.
- 참고 이미지를 그대로 복제하지 않고 이 콘셉트에 맞는 독자적인 표정·복장·무늬를 만든다.

## 학습 메모

외형 설계에서는 먼저 성격을 고르고, 그 성격이 **얼굴·색·실루엣·걷는 방식**에서 어떻게 보일지 연결한다. 같은 2등신 캐릭터라도 이 네 요소가 달라지면 작은 게임 화면에서 구분하기 쉽다. 반대로 애니메이션의 인상만 바꾸면서 실제 물리를 건드리면 캐릭터별 난이도와 랭킹 검증이 달라질 수 있으므로 아트와 게임 규칙을 분리한다.

## Out of scope

- 걷기·위험·넘어짐용 게임 프레임 제작, 애니메이션 원본 장수 확정
- 게임 코드·리더보드·해금 규칙 변경, iOS 또는 웹 배포
