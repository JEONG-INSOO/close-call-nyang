# Decisions: 앱 안의 개인정보·고객지원 경로

- Date: 2026-09-30
- Status: confirmed

## 확정 선택

- 사용자는 설정 하단에 개인정보처리방침·고객지원 두 링크를 추가하고 기존 랭킹 문의도 새 지원 페이지로 연결하는 추천안을 선택했다.
- 주소는 공개 페이지 Task에서 검증할 `/close-call-nyang/privacy/`, `/support/`이며 외부 브라우저로 연다. 기존 Expo Go 지원을 유지하고 WebView·광고·추적 SDK를 추가하지 않는다.
- 게임 물리/닉네임 변경 정책/프로필 삭제/랭킹 서버·저장 계약은 변경하지 않는다. 페이지 열기 실패는 기존 데이터 오류와 분리해서 안내한다.

## 순서와 출시 게이트

- 현재 공개 페이지 T02의 실제 배포 검증을 먼저 마친다. 그 뒤 이 단일 Task를 구현·검증·커밋하고 원래 출시 자료 P01-T03로 복귀한다.
- 원래 P01-T03는 한·영 **초안과 촬영 계획**을 준비한다. 최신 원본 캡처는 새 빌드 설치 후 P02-T02에서 확보하고 최종 문구 승인/제출 자료는 P02-T03에서 확인한다.
- 캡처와 최종 승인을 없애는 것이 아니라 소비 단계로 이동한다. 캡처가 없어서 빌드가 시작되지 못하는 순환 의존성을 제거하며 승인 없는 심사 제출은 계속 금지한다.

## 학습 포인트·경계

- 웹 페이지 게시와 앱 안에서 그 주소에 접근하는 UX는 서로 다른 작업이다. 하나의 상수에서 URL을 관리하면 설정과 랭킹의 경로가 갈라지지 않는다.
- 실제 iPhone Safari 복귀/링크 동작은 새 TestFlight 기기 QA로 확인한다. 단위/웹 테스트를 iPhone 성공으로 기록하지 않는다.
- 기존 더티 문서·`test`·미승인 PNG를 보존하고 선택 커밋한다. App Store Connect 로그인·심사 제출·가격/지역 설정을 이 링크 작업에서 수행하지 않는다.
