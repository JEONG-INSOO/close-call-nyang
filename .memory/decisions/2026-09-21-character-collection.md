# Decisions: 냥대리 3종과 달성 보상

## D01. 원본 캐릭터와 비율

- **Chosen**: 사용자가 첨부한 이미지의 큰 머리·작은 몸·짧은 팔다리라는 전반적인 비율을 참고하고 우리 게임의 캐릭터를 새로 만든다. 원본 이미지를 추출·트레이싱하거나 기존 얼굴/이마 무늬/로고/의상을 재사용하지 않는다.
- **Implementation default**: 기존 SVG 제작 방식과 크림색 털·직장인 정장을 유지한다. 전체 높이205, 귀 포함 머리118, 몸통51, 다리·구두36인 약1.74등신을 시작값으로 삼고 실제 게임 크기에서 조정한다. 이는 사용자 지정 수치나 법적 안전 기준이 아니다.
- **Rationale**: 큰 머리의 귀여움과 게이지 없이 몸 기울기·두 발·꼬리로 균형을 읽는 가독성을 함께 확보한다.

## D02. 세 캐릭터와 획득 조건

- **Chosen**: 이전 제안 세 가지를 모두 개발한다. 2번(허둥대는 직장인)은 기본 지급, 100%를 처음 달성하면1번(성실하지만 조금 지친 직장인), 10번 달성하면3번(능청스러운 베테랑)을 지급한다.
- **Implementation default**: 내부 ID는 rookie(기본2번), diligent(보상1번), veteran(보상3번). 임시 표시명은 허둥대는 냥대리/성실한 냥대리/베테랑 냥대리이다. 머리·몸 비율과 보행 구조는 공유하고 표정·눈썹·넥타이·작은 의복 디테일로 구별한다.
- **Rationale**: 외형 수집 보상을 제공하면서 공통 랭킹의 조건을 바꾸지 않는다. 속도·흔들림·조작력·실패 각도·커피 효과는 모두 동일하며 캐릭터별 능력치를 추가하지 않는다.

## D03. 달성 횟수의 해석과 저장

- **Implementation default**: 서로 다른 판에서 정상 플레이로100% 이상에 처음 도달할 때 판당1회 누적한다. 한 판의200%/1000%는 여전히1회다. 재도전은 새 판, 일시정지·재개·동일 결과 재표시는 같은 판이다.
- **Implementation default**: 앱·현재 브라우저 기기에 저장하고 오프라인 정상 플레이도 인정한다. 닉네임/리더보드 참여와 무관하다. 기기 간 동기화·복구는 추가하지 않으며 저장소 삭제 시 해금도 사라진다. 온라인 프로필만 삭제할 때는 로컬 캐릭터 수집을 유지한다.
- **Implementation default**: 게임 중100%에 도달하면 조용히 횟수를 반영·저장한다. 진행 저장용 completedRuns는0..10으로 포화해 해금에만 사용하며 게임 점수의 상한이 아니다. 개발용 가상 광고를 켠 시험 판은 수집 진행에 넣지 않는다. 저장 실패 시 현재 세션에서는 유지하되 영구 저장 성공으로 안내하지 않는다.
- **Rationale**: 10번 달성을10판의 성취로 해석하고 동일 판의 상태 업데이트/부활/재시도로 중복 지급하는 오류를 막는다. 로컬 데이터는 서버 검증된 랭킹 점수의 근거가 아니다.

## D04. 선택 및 안내

- **Implementation default**: 제목/결과 화면의 캐릭터 선택에서 세 캐릭터를 모두 보여주고 잠긴 것은 필요 달성 횟수를 표시한다. 해금된 캐릭터는 자유롭게 선택 가능하며 새 캐릭터를 얻어도 자동 교체하지 않는다. 선택은 다음 새 판부터 적용한다.
- **Implementation default**: 기존100% 숫자 색상 변경 규칙은 유지한다. 플레이 중 팝업·캐릭터 변신·축하 소리·진동은 추가하지 않는다. 새 보상은 결과 화면의 짧은 안내와 캐릭터 선택 버튼으로 확인한다. 제목으로 돌아갔거나 재실행했을 때도 해금된 카드는 선택 가능해야 한다.
- **Rationale**: 수집 요소가 균형 조작을 가리거나 캐릭터 실루엣을 플레이 도중 바꾸지 않게 한다.
