# Decisions: 현재 JPG로 App Store 캡처 시안

- Date: 2026-09-30
- Status: Confirmed

## D01. 입력과 품질
- Chosen: 사용자가2번(현재 JPG를 제출 규격으로 편집하고 먼저 보기)을 선택했다.1280×590 JPG 확대의 화질 한계를 보존하고 원본 PNG라고 표시하지 않는다.
- Rationale: 원본 재수신을 기다리지 않고 검토용 산출물을 만든다. 실제 제출/소개 승인과 기기QA는 별도 게이트다.

## D02. 화면 보존
- Chosen: 실제 앱 픽셀을 비율 유지 확대·합성하며 점수/닉네임/UI/캐릭터/잠금 상태를 생성하거나 바꾸지 않는다. AI는 배경 장식만 생성한다.
- Rationale: 실제 사용 화면이라는 출처와 심사 정확성을 유지한다.

## D03. 공개 시안 경계
- Chosen: 출근길1/캐릭터5/홈6/준비3/일시정지2의5장,2868×1320 opaque RGB PNG. 타인 닉네임이 있는4번 랭킹은 우선 제외한다. 제목은 시안이며 사용자 승인 전 원격 업로드·심사 제출하지 않는다.
- Rationale: 사용자에게 편집본을 먼저 보여주기로 한 약속과 개인정보 노출 최소화. 원래 App Store 준비 P02-T02는 미완료로 보존한다.

## Out of scope
- null 운영 입력/옛 심사 노트·개인정보/연령 설문·최신 빌드 촬영 확인은 원래 스토어/기기QA Task에서 처리. 이 시안 작업이 게임 코드·서버·IPA를 바꾸지 않는다.
