# Decisions: 성실한 냥대리 렉돌 외형

- Date: 2026-09-28
- Status: Confirmed

## D01. 범위와 순서
- **Chosen**: 보상 캐릭터 `diligent` 한 명만 먼저 제작·적용하고 육안 검토한다. `veteran`은 이번 작업에서 바꾸지 않는다.
- **Rationale**: 두 보상 캐릭터를 동시에 만들면 서로의 차이를 평가하기 어렵다.

## D02. 승인 시안
- **Chosen**: 사용자가 승인한 단일 렉돌 시안. 크림색 몸, 연회색 얼굴·귀·꼬리, 밝고 귀여운 여성스러운 파란 눈과 미소, 연보라 카디건·흰 블라우스·작은 리본·사원증, 짧고 자연스럽게 이어진 맨발 팔다리.
- **Rationale**: 기본 회색 태비의 남색 정장·갈색 눈과 털·복장·표정·색감을 분리한다. 과거의 `diligent` 피곤한 얼굴·넥타이 설정을 대체한다.

## D03. 게임 적용
- **Chosen**: 승인 시안을 바탕으로 게임용 걷기 동작을 제작한다. 캐릭터 ID `diligent`, 100% 달성 1회 해금, 수집 저장, 물리·점수·커피 조건은 변경하지 않는다.
- **Rationale**: 외형 변경이 기존 진행 데이터와 랭킹 검증에 영향을 주면 안 된다.

## D04. 배포 경계
- **Chosen**: 먼저 로컬 구현·검증만 진행한다. 웹/iOS 재배포는 이 승인으로 자동 수행하지 않는다.
- **Rationale**: 실제 기기 시각·성능 확인과 기존 미완료 출시 검증은 별도 단계다.

## Learning note
- 사용자 선택은 캐릭터 정체성·복장·털색·시안 승인이다. 코드 조사로 확인한 기본 PNG 리그, 옛 보상 SVG, 해금 ID/조건은 구현 제약이다. 새 외형이 실제 게임에서 자연스럽게 걷는지는 자동 테스트뿐 아니라 렌더링 확인이 필요하다.
