# Decision: 사무실 일상과 후반 이벤트
- 사용자 요청: 혼나는 장면 외 다양한 사무실 상황, 후반으로 갈수록 강한 이벤트 기울기.
- 2400px 반복 타일 안에 타이핑/복사기 걸림/발표/휴식/서류 운반/기존 업무 대화 6상황. 고정 SVG 및 transform 스크롤, 추가 타이머/매프레임 React 렌더 금지.
- eventStrength = 1.6 + 1.8*level (기존 계수0.65). level=log1p(max(0,distance-15)/35). 시작/속도/예고1.2초/활성0.7초/조작력 유지. 서버 복사본·규칙해시·golden 재생 동기화 필수.
- 이번에는 구현/검증/로컬 커밋. 원격 서버 및 웹 동시 배포는 별도 작업, 기존 점수 삭제/재설정 없음. 기존 사용자 더티 파일 보존.
- 후속 요청: 사표를 들고 뛰는 동료를 office 전용 resignation 이벤트로 추가. 이벤트 direction과 실제 힘/인물 이동 방향을 공유. 경고 뒤0.7초 활성 동안 통과한다.
- 후속 별도 요청: 광고 부활 후 점수도 자동 랭킹 포함(T02 필요). 오똥비131%는 확인된 publicId의 기존 운영 규칙 한 행만 수동 보정 승인; 자동 검증 기록과 혼동 금지.
- 추가: 속도 계수0.7→1.05로 강화(15% 이후 무상한 로그 증가), 100% 도달 시간 약90→83.65초. 웹 ESC는 playing/countdown/ad에서 정지하고 입력/clock 정리, 반복키·폼·모달에서는 가로채지 않고 ESC 자동재개 없음.
- 사용자 선택: 기존 규칙별 rows는 보존하고 user별최고를 같은 랭킹에 합산. 광고 부활은 서버 확인 첫 낙하에서1회 이어지는 child challenge로 검증한다(T02).
