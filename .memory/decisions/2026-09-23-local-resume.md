# Decision: 2026-09-23 Local Resume

## D01 범위
- 선택: 홈 → 이어하기만 DB 없이 추가한다.
- 제약: 랭킹, Supabase, 서버 API, 기존 저장 데이터 형식은 변경하지 않는다.

## D02 보존 범위
- 선택: 앱 종료 후에도 마지막 게임을 이어할 수 있도록 로컬 저장한다.
- 구현 후보: AsyncStorage 기반 단일 기기 저장.

## D03 저장 시점
- 선택: 일시정지, 홈 이동, 앱 백그라운드 전환 모두 저장한다.
- 근거: 사용자가 앱을 잠시 벗어나도 진행 상황을 잃지 않게 하기 위함.

## D04 재개 규칙
- 저장된 진행 상태가 유효하면 홈 화면에 이어하기를 표시한다.
- 이어하기는 저장된 거리·기울기·이벤트·커피·캐릭터 상태를 복원한다.
- 새 게임을 시작하거나 결과 화면에 도달하면 이전 이어하기 저장을 삭제한다.
