# Decision: 우측 진행 옆모습 캐릭터와 상황별 표정

- Date: 2026-09-22
- Trigger: 사용자 검토 — 현재 캐릭터가 정면으로 걷는 것처럼 보이지만 게임은 우측 횡스크롤이므로 우측 진행으로 보여야 한다. 넘어질 때 찡그린 표정이 필요하다.
- Supersedes (visual only): [reference-faithful-gait](./2026-09-22-reference-faithful-gait.md)의 정면 걷기 연출. 정면 버전은 T01 커밋으로 보존한다.

## 확정 사항
1. **각도**: 옆모습 + 얼굴만 살짝 정면. 몸통·다리·꼬리는 완전한 측면으로 우측을 향해 걷고, 얼굴은 반쯤 화면 쪽으로 돌려 두 눈과 표정이 읽히게 한다.
2. **범위**: rookie/diligent/veteran 세 종류 모두 옆모습. rookie로 옆모습 틀을 먼저 완성·승인받고, 같은 리그에 색/소품만 바꿔 보상 두 종에 적용한다. 캐릭터 ID·해금·카탈로그는 유지.
3. **표정 3단계** (렌더링 전용, `frame.value.angleRad`/`fallen`에서 파생):
   - 평소: 밝게 뜬 큰 눈 + 미소
   - 위험(|각도| 약 40도 이상): 동그랗게 커진 눈 + 벌린 입 + 땀방울 1개
   - 넘어짐: `> <` 찡그린 눈 + 일그러진 입
4. **T01 처리**: 정면 연결 걷기 T01을 검증된 상태로 먼저 커밋해 되돌아올 기준점으로 남긴다. P02-T03 미완료 변경은 커밋에서 제외한다.
5. **승인 순서**: rookie 옆모습 포즈 시트(걷기 4컷, 표정 3종, 커피, 넘어짐)를 브라우저 캡처로 먼저 승인받은 뒤 게임에 연결하고, 그다음 보상 두 종으로 확장한다.

## 기본값 (질문 없이 채택)
- 넘어짐 동작은 현재 방식 유지: 발밑 원점 기준 ±82도 회전. 옆모습에서는 오른쪽 기울기=앞으로 고꾸라짐, 왼쪽=뒤로 엉덩방아.
- 물리·규칙 해시 `nyang-v1-f7245064c9459310`·보상 조건·커피 15%·저장·랭킹은 변경하지 않는다. 표정 임계각은 표시 전용이며 실패 판정에 쓰지 않는다.
- 평면 파스텔 SVG 스타일, 기존 960×540 장면 좌표·발밑 원점·전체 높이/크롭 호환 유지.
- 배포·푸시·원격 작업 없음.

## 추가 결정 (2026-09-22, 시안 v5 검토 후)
6. **아트 스타일**: 사용자 레퍼런스(미니게임 천국 스타일 회색 태비 신입사원, 3/4 우측 보행, 갈색 외곽선, 흰 주둥이/가슴, 갈색 눈+큰 하이라이트, ω 입, 볼터치, 줄무늬 다리·꼬리, 음영 있음)를 따른다. 기존 "음영/광택 없는 평면 SVG" 아트 규칙은 이 캐릭터에 한해 폐기.
7. **제작 방식 B**: 그림은 외부 이미지 생성 도구로 부위별 분리 시트를 만들고, Claude는 배경 제거/분할 스크립트로 부품 PNG를 만든 뒤 기존 리그(발밑 원점, 부위별 회전)에 연결한다. 손으로 쓴 SVG 시안 v5(`docs/art/side-view-draft.html`, `grey-tabby-side-draft-v5.png`)는 포즈·피벗·표정 레이아웃 참고용으로만 쓴다.
8. 렌더링은 react-native-svg `<Image>`로 PNG 부품을 기존 AnimatedG 변환 아래에 배치하는 방향을 우선 검토한다(블러/필터 사용 금지, 모바일 성능). 기존 규칙·물리·보상·랭킹 불변 원칙은 그대로.
