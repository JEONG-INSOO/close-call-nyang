# 프로젝트 학습 목표 보강

계획은 실행 목록이 아니라 학습 가능한 청사진이어야 한다.

모든 Task에는 다음 항목을 포함한다.

- 수정 파일·심볼과 타입/스키마
- 데이터 흐름, 상태 전이, 오류 처리
- 완료 조건과 복사 가능한 검증 명령
- 생성 파일(Supabase 복사본, 웹 번들, replay fixture) 재생성 절차
- 초보자가 이해할 수 있는 '이 Task에서 배우는 개념'과 예상 디버깅 포인트
- 완료 후 docs/learning-notes.md에 기록할 질문 3개

Plan 단계에서는 코드를 수정하지 않는다. 기존 더티 파일과 생성 산출물의 처리 경계를 계획에 명시한다.
