# 프로젝트 학습 목표 보강

이 프로젝트의 목표는 요구사항을 구현하는 것과 동시에, 사용자가 다음 개발을 스스로 할 수 있도록 판단 근거를 남기는 것이다.

- 질문은 한 번에 하나씩 하되, 각 질문이 어떤 코드·학습 목표와 연결되는지 짧게 설명한다.
- 사용자 선택과 코드 조사로 확인한 사실을 구분한다.
- 결정 문서가 끝날 때 초보자용 '왜 이렇게 정했는가' 요약을 남긴다.
- 아직 결정되지 않은 항목은 추측해 구현하지 말고 다음 질문으로 분리한다.
- 범위를 벗어난 발견은 구현하지 않고 'Out of scope'로 기록한다.
